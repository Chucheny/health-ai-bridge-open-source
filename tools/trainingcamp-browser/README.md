# 华为训练营采集助手

Chrome 本机扩展提供「睡眠会话与分期」「运动首批」「运动续读」三个入口。0.3.0 的运动续读按网页的时间边界最多读取 5 页、100 条。重叠运动和相同时间的记录可能漏读。

1. 在 Chrome 扩展页启用开发者模式，选择「加载已解压的扩展程序」，选中本仓库的 `tools/trainingcamp-browser` 文件夹。
2. 打开自己的华为训练营页面，完成登录后打开采集助手。
3. 选择类别和北京时间日期（末日包含当天），核对后勾选确认。读取完成后点击「保存本地采集文件」。
4. 将文件交给 [Windows 工作台或 CLI](../../docs/BRIDGE_WORKFLOW.md) 进行离线预检，之后可在指定的自托管实例中确认导入。

扩展仅使用 `activeTab` 和 `scripting`，登录授权留在网页上下文。登录或权限失效、响应越界、分页停滞时停止。续读文件保存每页原响应与请求边界；睡眠、首批运动和旧格式仍可预检。生成文件含个人健康数据，应保存在私有位置。
